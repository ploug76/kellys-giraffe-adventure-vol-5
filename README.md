# Kelly's Giraffe Adventure Vol. 2: The Rhino Rumble

Kelly's giraffe is back! Run, ram, neck-grab, swing and slurp across 10 painted savanna levels and 5 boss battles to save Peter and the birthday cake from King Rumble the Rhino. A free game from Peter's Arcade.

Play: https://ploug76.github.io/kellys-giraffe-adventure-vol-2/

Controls: swipe and hold anywhere to move, swipe up or JUMP to jump, ACTION for head bonk, neck ram (double-tap), tongue, ring swing, neck grab (hold UP at a ledge) and neck pound (DOWN+ACTION in the air). Keyboard: arrows/WASD, Z/Space jump, X action, C ram, P pause, M sound. Controllers: stick/D-pad move, A jump, X/B action, Y ram, Start pause.

Original game: https://ploug76.github.io/kellys-giraffe-adventure/
